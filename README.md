# Customer Segmentation (K-Means)

## Overview

This notebook demonstrates customer segmentation using the K-Means clustering algorithm. It is ideal for marketing analytics projects and showcases preprocessing, scaling, PCA visualization, cluster selection, and interpretation.

## Notebook Contents

1. Load Mall_Customers dataset (or synthetic fallback)
2. Preprocess and scale numeric features
3. Reduce dimensionality with PCA for visualization
4. Select number of clusters with silhouette score
5. Fit KMeans and interpret cluster centers
6. Export cluster labels for downstream analysis

## How to run

* Place `Mall_Customers.csv` in the working directory or run as-is to use synthetic data.
* Run the notebook in Jupyter/Colab.

## Presentation notes

* Discuss how clusters inform marketing strategy (target high spenders, tailor promotions).
* Show cluster center profiles and sample customers per cluster.

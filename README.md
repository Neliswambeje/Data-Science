# EDA Notebook: Exploratory Data Analysis (Titanic example)

## Overview

This notebook demonstrates a practical, end-to-end Exploratory Data Analysis (EDA) workflow using the Titanic dataset. It is suitable as a portfolio piece to show your ability to clean data, visualize distributions, detect missing values, and create actionable summaries.

## Notebook Contents

1. Load libraries (pandas, numpy, seaborn, matplotlib)
2. Load dataset (Seaborn built-in or local CSV)
3. Inspect data shape, data types, and head
4. Missing value analysis and strategies
5. Univariate and bivariate visualizations
6. Basic feature engineering (family_size)
7. Export descriptive summary to CSV

## How to run

1. Open `01_EDA_Exploratory_Data_Analysis.ipynb` in Jupyter or Colab.
2. If running locally, ensure `titanic.csv` is in the working directory or change the load path.
3. Run cells top-to-bottom.

## What to highlight when presenting

* Data cleaning choices (why you imputed or removed values)
* Key insights (e.g., which passenger classes survived more)
* How engineered features add predictive value
